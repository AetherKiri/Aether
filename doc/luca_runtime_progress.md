# LucaSystem runtime

The macOS desktop host embeds the Rust AetherLuca runtime through `engine_runtime_provider_v1_t`. Game directories containing a Luca script archive and image PAK files are imported as `luca`, and the host passes their directory to the provider. `SCRIPT2.PAK` is accepted as the replacement script archive. Pointer input uses the runtime's native frame dimensions, and pending movies use the host media decoder with a viewport overlay and completion notification to the runtime.

The runtime identifies the script dialect, native canvas, initial title layout, new-game entry, fonts, and message-window resources for Summer Pockets REFLECTION BLUE, AIR, Kanon, Harmonia Full HD Edition, and LOOPERS. These paths have focused engine and provider coverage, but complete routes, presentation, menus, progress unlocks, and game-specific tasks and minigames remain unfinished. Reaching script EOF while skipping unsupported tasks or simulating movie completion does not establish full game support.

Save handling now reads the verified native prefix, packed variable segments, current instruction position, and eight GOSUB/FARCALL return records, with explicit compatibility for older runtime snapshots. Variable access follows the mounted capacity table, native packed widths and write ranges. All eight argument rows survive nested calls and save loading, including inheritance and sequential FARCALL argument evaluation. Loading validates instruction boundaries before changing the live session and re-presents the saved dialogue line. The writer still records only the verified prefix and return stack; scene layers, animation time, audio positions, history, progress, and task or minigame state are incomplete. Full original-game save compatibility has not been established.

Summer Pockets REFLECTION BLUE uses its game-specific message fonts and the original sliced frame masks, tinted black at the default opacity. Message reveals request new frames even when the background is static. Real-resource tests check readable text over a white background and completion without a click; text outlines, ruby, other window modes and all presentation options still need original-game comparison.

The macOS debug app builds and passes code-signature verification. The eight native Luca provider tests pass, including all five native canvases and START hit rectangles, and the Godot host lifecycle test passes. Headless host screenshots have also confirmed opening text in AIR, a snowy scene and ADV text in Kanon, and the illustrated opening and ADV text in LOOPERS. These checks cover the tested launch and frame paths; they do not replace original-game visual, audio, movie-overlay, or full-route comparisons.

The desktop CMake option is `AETHERKIRI_ENABLE_LUCA`, and `AETHERKIRI_LUCA_DIR` selects a checkout when configuring CMake directly. The normal macOS build reads `packages/AetherLuca`; changes in a separate engine working tree must first be copied through a committed submodule revision. Mobile and Web provider builds remain disabled.
