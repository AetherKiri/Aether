# WA2 Leaf TtT host

The leafttt-engine branch integrates the WA2 provider from packages/AetherInternal. See [Chinese overlay setup and final acceptance](wa2-chinese-overlay.md) for UTF-8 text, explicit fonts, and the final save-ready regression. The normal product retains its existing runtime defaults. A selective WA2 build can disable the default set and enable WA2 without requiring KiriKiri. It compiles the real interpreter, compositor, resources, text, persistent progress and save/load implementation.

On Windows, configure a Release Ninja build with the standard vcpkg toolchain and x64-windows-static-md. An existing compatible installed tree can be supplied through VCPKG_INSTALLED_DIR with VCPKG_MANIFEST_INSTALL=OFF; this only reuses dependencies and does not substitute runtime code. Add AETHERKIRI_RUNTIMES_DEFAULT=OFF, AETHERKIRI_ENABLE_WA2=ON, BUILD_ENGINE_API=ON, BUILD_GODOT_EXTENSION=ON, BUILD_TOOLS=OFF and ENABLE_TESTS=OFF. Build target aether_kiri_godot. Both the extension and engine_api DLL stage into the matching Godot project binary directory.

Import the Godot project once with Godot --headless --audio-driver Dummy --editor --path apps/godot_app --import. Run the playability probe with --script res://scripts/wa2_playability_probe.gd. Set AETHERKIRI_WA2_CONFIG to a JSON configuration with game_path and output_dir. Modes smoke, route and chapter cover real title input, normal clicks, explicit SKIP, strict original-row choices, save/load, and actual 1280x720 engine RGBA captures. Each output has an isolated user profile. The probe verifies audioSilent and rejects PLAY events; it acknowledges lifecycle events through the host protocol. Headless movie completion is explicit and is not a video-decoder fidelity check.

For full Normal route coverage, set mode=route, startup_script=2001, choice_plan to the verification/r6/plans/2025.plan file in the engine package, expect_flag=20 and pending_choice_roundtrip=true. No fallback choices are made. A pending-choice round trip tests the reference answer, a different answer, restoring the exact VM/globals, retained process-wide history, and reanswering without applying affection twice.
