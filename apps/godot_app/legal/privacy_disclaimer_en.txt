Aether Privacy Policy, Terms of Use, and Disclaimer

Version: 2026-11-26
Effective date: November 26, 2026

Welcome to Aether. Aether is an open-source visual-novel runtime and local media management tool. It can read visual novels, local videos, and external subtitles that you import. Please read this document carefully, especially the sections about risk, liability, and intellectual property.

If you are a minor, review this document with a parent or guardian and obtain their permission before use. By selecting “Agree and Continue,” you confirm that you have read, understood, and accepted this document. If you disagree, select “Decline” and stop using the app.

1. Privacy Policy

1.1 Data processed by the app

Aether requires no account and has no advertising or advertising tracking. To provide local library, runtime, and playback features, the app processes or stores the following information locally on your device:

- Games, videos, subtitles, cover images, and related files that you select or copy into the app’s directory.
- File paths, display names, cover references, recent-use timestamps, accumulated play time, and video playback positions.
- Language, interface, rendering, compatibility, and diagnostic preferences.
- Saves, caches, and temporary files required for operation.
- Local logs, performance data, error context, screenshots, or diagnostic archives created when diagnostic features are enabled. Diagnostics may include file names, paths, game titles, rendering information, and error context. Review them before sharing.

1.2 Use of data

Except for the optional telemetry described in section 1.7, the app uses this information only on your device to display your library, run compatible content, restore settings and playback positions, preserve game progress, troubleshoot errors, and improve local operation. The developer does not proactively upload your imported games, videos, subtitles, saves, logs, or other personal files to a developer server.

1.3 Network access and external content

The core library and local playback functions can operate offline. However, imported game scripts, media, or external links may request network resources, and compatibility interfaces may attempt network access when instructed by imported content. These requests are initiated by content you choose to run and do not mean that the Aether developer is collecting data. Import only content you trust. You are responsible for data charges and for the privacy practices of external services.

1.4 Sharing

The developer does not sell your data. When you share or export files or diagnostics, the recipient you select handles the data under its own privacy practices. Section 1.7 describes who receives optional telemetry.

Open-source components used by Aether perform parsing, decoding, rendering, and runtime work locally. The developer does not use those components to proactively transmit your content to their authors.

1.5 File permissions and local security

On iOS, Aether reads content that you place in its Files app directory. On other platforms, it reads relevant locations after you import files or grant the corresponding file permission. Core functionality does not require Contacts, Location, Camera, Microphone, or advertising-tracking access.

iOS file sharing may allow the app directory to be accessed through the Files app or a trusted computer. Protect your device, backups, and exported files. Do not run unknown, modified, or potentially malicious content.

1.6 Retention and deletion

Data remains on your device until you delete the corresponding files, remove library records, clear app data, or uninstall the app. Removing a library record may not delete the original file; delete original files through the Files app or a file manager. Copies, backups, and files shared elsewhere are not automatically deleted when the app is uninstalled.

To stop using the app or withdraw your decision to use it, stop use and uninstall it. System file permissions can be revoked in device settings.

1.7 Optional usage and compatibility telemetry

Telemetry is off by default. Agreeing to this document does not enable it. If the build supports telemetry, you can choose to enable it in Settings → Privacy. Your choice has no effect on core functionality. A change to the telemetry notice may require you to opt in again.

- App usage: a random installation ID links events from the same installation so the team can measure app launches and time spent in the foreground.
- Device compatibility: operating system, processor architecture, memory capacity range, and graphics card family help identify affected device groups.
- Release regressions: app version, build, and release channel help identify problems introduced in particular releases.
- Game compatibility: game engine, launch outcome, foreground play time, and the exact displayed titles of games played or that failed to start help identify affected games. If no title is available from the game, the displayed name may be the name of a local file or folder. Titles that fail validation are omitted.
- Performance and failures: frame rate, peak memory use, loading time, and predefined error codes help diagnose slowdowns and failures. The memory metric is the highest sampled value and varies by platform. On the web, it measures WebAssembly linear memory capacity.

Telemetry excludes full file paths, URLs, raw logs, screenshots, saves, and file contents. We remove received records from the live database after 90 days. Recovery backups follow a separate retention period. Our network provider processes your IP address when you connect. Aether does not include it in the telemetry payload or store it with events. We use the data for the purposes described above and never use it for advertising or sell it.

Turn off sharing at any time in Settings → Privacy. This immediately stops collection and sending and clears the local installation ID and any unsent telemetry. Events already received expire under the retention period above. Use the contact in section 5 for privacy requests, and avoid including sensitive information in public issues.
